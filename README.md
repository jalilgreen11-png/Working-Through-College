A three-page website built for **CIS 3610 — From Concept to Website: The Web Design Process in Practice**. Spring 2026.

The site is a guide for Cal State LA students who work while in school. It introduces four practical systems for managing the semester: schedule, energy, communication, and course load.

## About the Project

This site promotes a cause I care about: making college survivable for working students at Cal State LA. According to U.S. News (2024), 86 percent of first-year students at Cal State LA receive need-based financial aid, and many work full-time or near full-time while enrolled. Standard college advice does not always fit this reality.

The site presents four systems working students can apply right away:

1. **Build a Realistic Schedule** — Map fixed blocks first, plan around what is actually left.
2. **Manage Your Energy** — Match harder work to your better focus windows.
3. **Communicate Early** — Reach out to managers and professors before conflicts.
4. **Adjust Course Load When Needed** — Recognize when the load is wrong for the semester.

## Technical Implementation

### Stack
- **HTML5** with semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`)
- **Bootstrap 5.3.3** via CDN for responsive grid and components
- **System default fonts** (no external fonts loaded)

### On-page SEO
- Unique `<title>` and `<meta description>` tags on each page
- Meta keywords and author tags
- Semantic heading hierarchy (`<h1>` → `<h2>` → `<h3>`)
- Descriptive anchor text on all links

### Responsive Design
- Bootstrap's mobile-first grid system
- Collapsible navigation on small screens via Bootstrap navbar
- Tested on desktop and mobile viewports

## Design Decisions

**Color palette:** Cal State LA's institutional black, gold, and white. Black carries the primary structure. Gold is used as an accent on key actions and statistics. White space carries most of the visual work.

**Typography:** System sans-serif fonts for fast loading and clean readability across devices.

**Layout:** Each page follows a consistent top-to-bottom narrative structure with the same nav and footer for visual consistency across the site.
